# Summary: 2026-10-11

## Changes
- **Structure snapshots.** All six structures can now be saved as plain data and rebuilt exactly (`snapshot()` and `restoreStructure()`). The fight state needs this so it can be stored as JSON and replayed. A restored structure answers the same and keeps behaving identically as more events arrive, including Reservoir Sampling's random choices.
- Corrupted snapshots are rejected with a clear error.
- 46 new tests for snapshots.
- **Stream generator.** Enemies now produce seeded streams shaped by five traits: Variety (256 to 4 million values), Skew (Zipf), Churn (deletes), Growth (bursts that compound each turn) and Drift (the heavy values change owners every few turns). The rank-to-value mapping is rebuilt from the seed, so the saved state stays a few hundred bytes even at the largest size.
- **Exact ground truth.** A `LiveSet` records what is truly live, the heaviest value and its count, the distinct count, and the deleted ("ghost") values. Challenges are graded against it.
- 49 new tests for the generator; 218 pass and lint is clean.
- A scripted-fight test for M2 is drafted. It fails until the fight code exists and is committed together with it.
