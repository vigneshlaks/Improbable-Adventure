# 2026-10-19

- **The Cunning enemy is in, and Seeded is now worth taking.** A Cunning enemy studies the structures you have deployed and adds values aimed at them: for Count-Min, values that land on the same counters as its favorite value; for LogLog and HyperLogLog, values with the rarest hash patterns; for filters, never-seen values the filter wrongly says it has seen, offered as Presence decoys. Measured: an open HyperLogLog that should say 600 says about 22,000; one with the Seeded enchantment says about 700. Seeded works because the enemy reads your structure with the public hashes only, and the secret seed is never given to it (a test checks that). Cunning costs the Greedy bot about 7 points (it wins 37% of runs; 44% with Cunning off), and Seeded wins back about one for the bots, which cannot see the trait; a player reading "studies your structures" can do much better.
- **A bug found on the way:** an Elite with only the Likeness weak point and a big stream could never be struck, because the game only shows Likeness for sets of up to 1,000 values. The Oracle lost one run in 200. Likeness is now only a weak point of small-stream enemies.
