# 2026-10-19

- **The Cunning enemy is in, and Seeded is now worth taking.** A Cunning enemy studies the structures you have deployed and adds values aimed at them: for Count-Min, values that land on the same counters as its favorite value; for LogLog and HyperLogLog, values with the rarest hash patterns; for filters, never-seen values the filter wrongly says it has seen, offered as Presence decoys. Measured: an open HyperLogLog that should say 600 says about 22,000; one with the Seeded enchantment says about 700. Seeded works because the enemy reads your structure with the public hashes only, and the secret seed is never given to it (a test checks that). Cunning costs the Greedy bot about 7 points (it wins 37% of runs; 44% with Cunning off), and Seeded wins back about one for the bots, which cannot see the trait; a player reading "studies your structures" can do much better.
- **A bug found on the way:** an Elite with only the Likeness weak point and a big stream could never be struck, because the game only shows Likeness for sets of up to 1,000 values. The Oracle lost one run in 200. Likeness is now only a weak point of small-stream enemies.
- Left: Merge with multi-enemy fights, SimHash, the Likeness fusions, Dyadic Count-Min, exporter code for the new structures, retraining the learned player, the first CI run.

- **Milestone 9 is finished.** The last pieces: eight more structures and fusions (Scalable and Spectral Bloom, Dyadic Count-Min, Quotient Filter, SimHash, Locality-Sensitive Hashing, HyperMinHash, Theta Sketch), each tested against its own error bound; fights with two enemies at once (slots on the odd and even positions watch different enemies, and the Merge enchantment or a Theta Sketch answers for both); and a final balance pass. A rule was added so a recipe can need two copies of the same structure (the second copy turns up as a reward). Results (300 runs): the Oracle still wins every run, the Greedy bot wins 31%, the Prober 23%, the Cautious 11%, Random none. Two-enemy fights were the biggest single cost, so they are rarer now. The spec's 55 to 70% target for Greedy is still missed, as it has been since milestone 4; each new kind of enemy took a few points off a bot that does not read the enemy's description. Some honest findings: SimHash is weak when a few values repeat a lot (it flags almost nothing), the Scalable Bloom Filter is only a hedge for an unknown size (a well-sized plain Bloom Filter beats it), and the Locality-Sensitive Hashing fusion trades precision for never missing a real copy. Next is milestone 10 (what you chose): toolkit code for the new structures, retraining the learned player, and the first real CI run.
