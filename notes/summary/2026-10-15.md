# Summary: 2026-10-15

## Changes
- **Frequency fights, tuned.** A diagnosis showed that with the starting structures Frequency is a gamble on whether Exact Memory happened to see the shielded value (bots win about 75% when it did, and the rest are blocked). The "proper" tool, the Count-Min Sketch, was a trap: it overestimates about three times on these streams, and the squared penalty for overshooting cut its damage to a ninth (the greedy bot won 32% with it against 75% by gambling).
- The overshoot penalty is now linear instead of squared (`OVERSHOOT_EXP` 2 to 1). With the sketch, the greedy bot now wins about 78%, the cautious bot 47% and the random bot 6%, so it is as good as the gamble for a careful player and still rewards skill. With the starting structures nothing changes, because the sketch is not owned yet. Values below 1 made Frequency nearly trivial.
- Not fixed: the cautious bot still loses Frequency fights with the starting set (it strikes a very wide upper bound), and wrong strikes (38% for the greedy bot on Minions) are above the 10 to 30% target. Both are for the run loop and later tuning.
- **Fewer tests, same checks.** Tests that were generated one per parameter set (stream mixes, structure kinds, tiers, bots) are now one test per group that runs every case and names each failure. The count fell from 606 to 444 with no assertion or statistical bound changed. 444 tests pass and lint is clean.

- **The run loop exists (first step).** A run is now a sequence of fights: five Minions, a rest stop, an Elite, then the Boss. Certainty carries from fight to fight. After each won fight you pick one of three rewards: a new structure (such as the Count-Min Sketch) or an upgrade (more Space, one more slot, more maximum Certainty, Certainty restored after each fight, or stronger strikes). The rest stop restores 30 Certainty. A scripted run that always strikes the true answer wins the whole act, so the carry-over does not make it unwinnable. 474 tests pass.
- **Not yet:** the HyperLogLog structure and fusion, enchantments, bots playing whole runs (so no balance numbers for the act yet), and run mode in the terminal.
