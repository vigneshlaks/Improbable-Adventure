# Summary: 2026-10-13

## Changes
- **Content files.** The game's data now lives in validated JSON: fight settings and enemy tiers in `balance.json`, the trait tables and weak point hints in `traits.json`, and a description of each structure (name, aliases, what it answers, knob range, help text) in `structures.json`. A test checks that the structure descriptions match what the engine's structures really do.
- **Enemy generation.** `generateEnemy(seed, tier)` designs an enemy: which of the five stream traits are above Low and how strong, and which weak points it has, with traits nudging the choice (a heavily skewed enemy is likelier to be a Frequency enemy).
- **Fight config builder.** `buildFightConfig` turns the content into everything the engine needs to start a fight.
- 30 new tests, including a random-play fuzz across Minion, Elite and Boss fights.
- **Command parser.** Typed commands (`deploy bloom 6000 600`, `ready`, `strike confirmed`, `strike high 2`, and so on) become engine actions. It checks free Space, knob ranges and slots, numbers slots and targets from 1, explains mistakes, and suggests the likely command or structure for a typo. It never throws.
- **Narrator and screens.** Engine events become story text from templates in content, the enemy is described by its traits, and the status, query and help screens are rendered. A mistyped template variable is caught when the content loads.
- Both live in a new shared package, `ui-core`, so the CLI and the later web UI use the same code.
- 69 new tests for the parser, narrator and narration content, including three whole fights played from typed commands; 384 tests pass and lint is clean.

## Known limitations
- Tier sizes, HP, attack, turn limits and the weak point hints are placeholders for the simulator to tune.
- The starting loadout has no Count-Min, so Frequency enemies are harder to answer in a starting-loadout fight.
- LogLog reports 95% bounds on tiny streams where its error law does not hold.
- Linear Counting's infinite upper bound has no JSON encoding yet.
- CI has not run yet.
