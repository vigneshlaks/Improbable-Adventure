- **The browser check of the web version is done.** The heatmap, register bars and the other structure views look right. One bug turned up (a small strip only filled part of its width) and is fixed. A run played to its end in the real page offers the replay download.
- **Milestone 7 (the exporter) has started with the sizing step.** Given a real workload (how many items, how many different ones, how much error is acceptable, how much memory there is) it now works out the size of each structure: for example, a Bloom Filter for 1,000 items at 1% false positives needs about 9,600 bits and 7 hashes. Each size is checked against the game's own structures over hundreds of random streams, and the check caught that a first formula landed slightly over the target.
