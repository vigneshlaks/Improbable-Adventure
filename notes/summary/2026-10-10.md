- LogLog reports 95% bounds on tiny streams where its error law does not hold.
- Bloom at `k = 14` runs about 15% above the textbook false-positive rate. Now explained: the shortcut that derives all 14 hash positions from two hashes occasionally gives two values the same positions. It doesn't change any in-game answer today, so it was accepted and documented, and the test is unchanged.
- Linear Counting's infinite upper bound has no JSON encoding yet, and structures have no JSON snapshot form.
- Some coverage tests pass with the maximum margin and would not catch a small slip.
- CI has not run yet.
